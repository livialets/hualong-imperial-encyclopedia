ENCICLOPÉDIA IMPERIAL DE HUÁLÓNG — PUBLICAÇÃO NO GITHUB PAGES

Autoria: CachinhoDeCaramelo

Este ZIP contém index.html, style.css, app.js, lore.json, regions.json, original-lorebook.js e assets/.
Não altere os nomes dos arquivos nem mova a pasta assets.

No GitHub (tablet Android):
1. Abra github.com/livialets/hualong-imperial-encyclopedia e entre na conta.
2. Use Add file > Upload files (na visualização de desktop do navegador, se necessário).
3. Extraia o ZIP primeiro. Envie os arquivos da raiz para a raiz do repositório; envie os arquivos de assets para a pasta assets, preservando os nomes.
4. Para substituir arquivos existentes, use o mesmo caminho/nome e confirme o commit. Se o GitHub não permitir o envio de uma pasta, entre na pasta assets e envie os arquivos por lá.
5. Verifique Settings > Pages: Deploy from a branch, branch main, folder /(root), se essa for a configuração atual.
6. Aguarde a publicação e abra https://livialets.github.io/hualong-imperial-encyclopedia/ . Atualize a página se necessário.

IMPORTANTE: o GitHub não extrai ZIP automaticamente na interface web. O ZIP deve ser descompactado antes do upload. Faça backup do repositório antes de substituir os arquivos.

A navegação usa âncoras (#...), sem roteador nem serviços externos. Os arquivos JSON são carregados por fetch, então teste via GitHub Pages ou servidor HTTP, não diretamente via file://.
